# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial MVP release
- Privacy-first analytics tracker script (<10KB gzipped)
- Fastify collector service with ingestion, realtime streaming, and verification
- Next.js dashboard with authentication, site management, and analytics views
- Event governance with allowlist-based prop storage
- Path normalization with configurable rules
- Cardinality protection for dimension values
- Session tracking and funnel analysis
- Transparency panel showing what's collected and dropped
- Self-hosting support via Docker Compose
- Open source with MIT license
